# 0003: Use Catch2 for unit tests

## Context

The project needs unit tests that are readable and maintainable to help detect
bugs and prevent regressions. An alternative is to write and maintain a
project-specific test harness.

## Decision

Use Catch2 as the unit testing framework. Its tests are built with the project
and registered with CTest.

## Status

Proposed

## Consequences

Catch2 supports readable, maintainable unit tests, making it easier to detect
bugs and prevent regressions. It is an external dependency, fetched at the
pinned version 3.8.1 during CMake configuration.
